# 夢隙：醒來之前

使用 HTML、CSS、JavaScript 與 Three.js 製作的第一人稱 3D 夢核／怪核密室逃脫。五個場景包含影子對齊、道具收集、照片拼圖、鏡面反射及記憶組合；每關完成後自動保存在此瀏覽器。

## 本機執行

安裝 Node.js 後，在此專案資料夾執行：

```powershell
npm ci
npm run build
npm run dev
```

開啟終端顯示的 **http://127.0.0.1:4173/**。伺服器只提供本機靜態檔案，沒有後端遊戲服務、帳號或資料庫。停止時在終端按 Ctrl+C；如需改埠號，可先在 PowerShell 設定 `$env:PORT = '4174'`。

`npm run build` 將固定版本 Three.js 0.186.1 及授權複製到本機素材目錄，並建立可部署的 `dist/`。遊戲不依賴外部 CDN；將 `dist/` 內容放到一般靜態網站空間即可。請透過 HTTP 網址使用，勿直接雙擊 HTML。

## 操作方式

| 操作 | 按鍵／方式 |
| --- | --- |
| 移動、環視 | WASD、滑鼠；未鎖定時可按住場景拖曳環視 |
| 互動、拿取 | 靠近物件按 E，或點擊畫面中央的互動按鈕 |
| 放下、檢視 | G、R；檢視時拖曳旋轉，R／Esc 離開 |
| 物品欄、提示 | Tab、H |
| 暫停、退出操作介面 | Esc |
| 輔助探索 | 點「探索導覽」，選擇目前可見的物件，沿可通行路線走近；WASD 可取消 |

物件操作介面會暫停玩家移動與環視。影子物件可調整左右、前後與角度；照片碎片可拖曳或點選放置並旋轉；鏡面角度每次調整 15°。靠近物件才能使用，不提供直接跳關。

## 五關流程

1. **失焦的房間：** 抽屜中的回診提醒觸發怪核，移動及旋轉月亮燈、兔子玩偶、花瓶，使影子對齊。
2. **沒有盡頭的走廊：** 拿起手機，探索抽屜與家具，找齊鑰匙、孩子的畫、未寄出的信並放入凹槽。
3. **少了一個人的晚餐：** 從四個位置找回照片碎片，拼合並翻面查看訊息。
4. **鏡子裡的陌生人：** 拿手電筒、旋轉三面立鏡，讓光線依序經過三個標記，再讀取抽屜內三份紀錄。
5. **清醒之門：** 依序放入前四片記憶，觀看投影，將第二關的信投入信箱後走向結局。

故事、精確謎底與完整驗收條件分別見 `brief.md`、`agent.md`、`verify.md`。遊戲以約 25 分鐘設計，沒有強制倒數；實際時長需由玩家試玩驗證。

## 存檔

每關完成及進入下一關時，使用 localStorage 的 `dream-gap-save-v1` 儲存進度。關閉或重新整理後，從主畫面的「繼續上一次的記憶」載入。同一網站來源與瀏覽器才能讀取同一進度；無雲端同步。第二關信件的跨關資格會保留。

寫入失敗時會顯示重試提示，不會假裝已儲存。開始新遊戲會在確認後取代該來源的進度；未通關時的解謎擺位不保證即時保存。

## 驗證

```powershell
npm test
npm run build
```

自動化測試涵蓋五關成功與失敗條件、光線反射、存檔恢復、損壞與封鎖儲存、跨關信件、碰撞與路線。自動化邏輯測試與實際瀏覽器操作分開記錄，詳見 `test.md` 及 `verify.md`。

## 素材與結構

- `public/`：可執行的靜態網站來源。
- `public/assets/dreamcore/`：Image Gen 生成貼圖、家庭照片、完整提示詞與清單。
- `public/vendor/`：固定版本 Three.js 原始發佈檔及 MIT 授權。
- `references/visual-style/`：九張使用者提供的風格參考原圖，未修改。
- `public/engine.mjs`：五關狀態、謎底與存檔驗證。
- `public/scene.mjs`：Three.js 場景、模型、投影與互動目標。
- `public/game.mjs`：操作介面、導航、故事、聲音與遊戲流程。
- `tests/`：Node.js 原生測試。

環境音及機關聲由瀏覽器合成；系統語音可用時朗讀並保留文字。右上角暫停選單可關閉聲音。原始參考圖只供開發風格參照，遊戲實際場景使用程式建立的模型及生成素材。
