# 夢隙：醒來之前

使用 HTML、CSS、JavaScript 與 Three.js 製作的第一人稱 3D 夢核／怪核密室逃脫。六個場景包含影子對齊、連鎖找物、照片拼圖、記憶電話總機、電路點燈及黑暗投信；每關完成後自動保存在此瀏覽器。

## 線上遊玩

**[開啟《夢隙：醒來之前》](https://shao077777714.github.io/midexam/public/)**

GitHub Pages 目前從 `main` 的根目錄發布，遊戲入口位於 `public/index.html`，因此網址需要保留 `/public/`。不必啟動本機伺服器，可直接把連結分享給其他人。

後續更新遊戲時，先將開發分支合併到 `main`，等待儲存庫的 Pages 部署完成，網址會維持相同。本機網址與公開網址使用不同的瀏覽器存檔，進度不會自動轉移。

## 本機執行

安裝 Node.js 後，在此專案資料夾執行：

```powershell
npm ci
npm run build
npm run dev
```

開啟終端顯示的 **http://127.0.0.1:4173/**。伺服器只提供本機靜態檔案，沒有後端遊戲服務、帳號或資料庫。停止時在終端按 Ctrl+C；如需改埠號，可先在 PowerShell 設定 `$env:PORT = '4174'`。

`npm run build` 將固定版本 Three.js 0.186.1 及授權複製到本機素材目錄，並建立可部署的 `dist/`。遊戲不依賴外部 CDN；將 `dist/` 內容放到一般靜態網站空間即可。請透過 HTTP 網址使用，勿直接雙擊 HTML。

## 操作方式

| 操作 | 按鍵／方式 |
| --- | --- |
| 移動、環視 | WASD；滑鼠直接環視；Alt 按一下切換游標 |
| 互動、拿取 | 靠近可拿取物品後雙擊直接拿取；E 或中央互動按鈕仍可互動 |
| 放下、檢視 | G、R；檢視時拖曳旋轉，R／Esc 離開 |
| 物品欄、提示 | Tab、H |
| 暫停、退出操作介面 | Esc |
| 輔助探索 | N 開啟探索導覽，選擇目前可見的物件，沿可通行路線走近；WASD 可取消 |

物件操作介面會暫停玩家移動與環視。影子物件可調整左右、前後與角度；照片碎片可拖曳或點選放置並旋轉；總機依日期排列錄音，配電箱單擊旋轉，按住拖到另一格交換位置，放到格外取消。靠近物件才能使用，不提供直接跳關。

探索預設隱藏游標，直接移動滑鼠環視；按一下 Alt 顯示游標並停止環視，再按一下恢復。介面自動顯示游標。優先鎖定滑鼠，被瀏覽器拒絕時提供自由環視及邊緣轉向回退。Esc 暫停、開選單及解謎面板直接有游標。全遊戲已移除水面、潮線與波紋，維持固定移動速度。

提示只在按H或燈泡後開啟，每次從第一則含蓄文字開始，最多主動翻閱五則；不自動顯示目標側窗或等待提示，也不直接提供謎底。舊提示欄位保留供存檔相容。主要文字採置中楷體／明體排版，保留電路和拼圖本來的空間關係。

## 六關流程

1. **失焦的房間：** 抽屜中的回診提醒觸發怪核，移動及旋轉月亮燈、兔子玩偶、花瓶，使影子對齊；每件成功後鎖定，不可再移動。
2. **沒有盡頭的走廊：** 拿起手機，查看手機通知的時間，調好座鐘才取得鑰匙；移椅取得孩子的畫，依圖形順序解開信匣取得信，三物入槽才通關。
3. **少了一個人的晚餐：** 從九個位置找回照片碎片，點選發亮後用 Q／E 或按鈕旋轉，支援拖放、交換及取回，拼合並翻面查看訊息。
4. **爸爸的空房間：** 觸發諮詢紀錄，從工作檔案匣、答錄機、木櫃、孩子的留言匣與角落矮櫃找齊五段錄音，在總機依清楚日期由早到晚排列，再接通。五段日期同時可見，選取可讀完整逐字稿，可取回重排；自動接線與調頻，靜音也可解。
5. **清醒之門：** 尋找燈泡／燈罩／電池修復三盞燈，拖放交換並旋轉配電箱導電片接通三個接口。依過去→現在→未來點燈，觀看投影取得改變，解鎖第六關。
6. **最後一封信：** 約52公尺黑暗走道，途中浮現爸爸的紅字回憶、同一家人的生日／公園／睡前家庭照片與周邊眼睛，最後抵達信箱。投入第二關的信後，親自開啟最後的門才播放醒悟結局。

每關完成只解鎖出口並儲存。按成功視窗的「回到場景，走向出口」後，仍須靠近實體門按E或準星雙擊，看到門打開才離開；導覽不代為開門。新增三張家庭照以原爸爸／媽媽／孩子為身分參考，套用於各關相框與第六關，原第三關九片拼圖保持原圖。

故事、精確謎底與完整驗收條件分別見 `brief.md`、`agent.md`、`verify.md`。遊戲以約 25 分鐘設計，沒有強制倒數；實際時長需由玩家試玩驗證。

## 存檔

平常只顯示右上角的雙肩背包圖示。點圖示或按 **Tab** 開啟右側正方形物品欄，顯示本關已收集道具的縮圖、名稱與用途狀態；點選後高亮並保留面板。點右上叉叉、背包或按 **Tab／Esc** 收起，回到探索後按 **R** 檢視選取物件。物品多時只捲動格子區，不會展開全螢幕。用過的物品保留並標示已放置／已安裝，仍可選取檢視；放下不會刪除任務道具，第二關信件在第五、六關重新顯示，第六關投入。

每關完成及進入下一關時，使用 localStorage 的 `dream-gap-save-v1` 儲存進度。關閉或重新整理後，從主畫面的「繼續上一次的記憶」載入。同一網站來源與瀏覽器才能讀取同一進度；無雲端同步。第二關信件的跨關資格會保留。儲存鍵沿用原名稱，格式升為 version 8；接受 v1～v7。保留已完成關卡、記憶、信件與已完成投影；舊版未完成第四關保留原有三錄音，需補找新增兩段；已通關不撤回。第五關保留既有擺位，新機關擺位與步驟可存檔續玩。第六關分段回憶保存檢查點，重載從最近回憶處續走；投影中重載可再次播放，不會卡在黑畫面。新存檔保存各關結尾旁白outroHeard、開門與歷史提示欄位；未聽完重載須重新完整播放，已聽完並保存不重播。舊版已看到結局仍為完成，已解謎但尚未離開的本關改從實體門離開。

寫入失敗時會顯示重試提示，不會假裝已儲存。開始新遊戲會在確認後取代該來源的進度；成功操作後亦會保存中途狀態。

互動預覽共用繪圖環境；繪圖中斷時會嘗試恢復，無法恢復則提供重新載入提示。如果舊頁面已白屏，載入修正版後按 Ctrl+F5，再選「繼續上一次的記憶」，不需要清除網站資料或開始新遊戲。公開站仍須等待開發分支合併 main 後才有修正。

## 驗證

```powershell
npm test
npm run build
```

自動化測試涵蓋六關成功與失敗條件、錄音／接線與真正電路連通、存檔恢復、損壞與封鎖儲存、跨關信件、碰撞與路線。自動化邏輯測試與實際瀏覽器操作分開記錄，詳見 `test.md` 及 `verify.md`。

既有改善包含道具落地、動態家具碰撞、安全路徑、直接環視、短促後微透明的周邊眼睛、倒置櫃、落地破舊玩偶、剝落牆皮及較暗的怪核燈光。第三關電視有清楚的照片托架，第四關五錄音總機，第五關電路與三燈。現行保留親自開門、家庭照、主動含蓄提示，修復第二關手機支撐。實際測試範圍見 test.md；完整 Chrome／Edge 矩陣與新玩家時長仍待驗收。

本輪場景補足有支撐及碰撞的生活家具：前五關各新增4／4／8／6／4組，第二關右側有候椅、書櫃與盆栽，第三關補齊沙發、茶几、櫃架及落地燈。地板為實體分板／石板接縫，牆面有程序漆面凹凸、踢腳板與牆裙，家具有柔化邊緣。第五關平台增加投影機、雙喇叭、接線及供電指示燈；第六關整座門及照明投信儲存後才出現，眼睛／照片／文字每次行走使用穩定變化的配置。

## 素材與結構

- `public/`：可執行的靜態網站來源。
- `public/assets/dreamcore/`：Image Gen 生成貼圖、家庭照片、完整提示詞與清單。
- `public/vendor/`：固定版本 Three.js 原始發佈檔及 MIT 授權。
- `references/visual-style/`：九張使用者提供的風格參考原圖，未修改。
- `public/engine.mjs`：六關狀態、謎底與存檔驗證。
- `public/scene.mjs`：Three.js 場景、模型、投影與互動目標。
- `public/game.mjs`：操作介面、導航、故事、聲音與遊戲流程。
- `public/controls.mjs`、`public/phenomena.mjs`：滑鼠鎖定／自由環視、固定移動速率及附著／落地異象。
- `public/guidance.mjs`、`public/guidance-time.mjs`：目前目標、五層提示與可暫停／保存的停滯計時。
- `public/models.mjs`、`public/spatial.mjs`、`public/atmosphere.mjs`：道具造型、支撐／碰撞、無盡遠景及壁面眼睛。
- `public/surfaces.mjs`、`public/dressing.mjs`：共享程序表面材質、實體建築接縫與成組生活陳設。
- `public/audio-director.mjs`、`public/voice-clips.mjs`：懸疑音景、完整配音與暫停／靜音生命週期。
- `public/finale-layout.mjs`：每次行走的回憶配置。
- `tests/`：Node.js 原生測試。

遊戲持續播放本專案原創的夢核／怪核／黑暗走道懸疑音景；配音時背景降為24%，暫停與背景頁停止播放時鐘，靜音關閉全部聲音。旁白改為外部edge-tts產出的中文爸爸神經語音MP3；六關結尾必須完整播完才能返回開門。第五關投影分四段同文音檔，字幕依每段自然播放結束換頁，不再使用瀏覽器Web Speech。這是AI合成，不是真人錄音或ChatGPT聲音複製。來源、完整腳本與SHA-256見public/assets/audio/README.md及voice-v2/manifest.json；玩家不需安裝生成工具或提供金鑰，靜音不跳過播放時序，音訊失敗可等長閱讀字幕。第四關只在通關播放結尾，五帶逐字稿與排序保留。右上角燈泡開啟任務提示、喇叭切換全部聲音、星芒切換眼睛動態，另有雙肩背包與暫停圖示，滑入可看說明。背包平常收起，點背包或 Tab 開啟右側方形物品欄，直接選物後高亮；叉叉、背包、Tab／Esc 收起，關閉後 R 檢視選取物品。探索導覽保留 N 快捷鍵；系統減少動態偏好另有靜態回退。原始參考圖只供開發風格參照，遊戲實際場景使用程式建立的模型及生成素材。

探索滑鼠直接環視，保留 ±85°；按一下 Alt 顯示游標操作右上角，再按一下恢復。面板直接有游標；Esc 暫停。怪核窗外眼睛持續可見，降低動態時維持靜態。

場景配樂由遊戲在背景播放。夢核使用 Kevin MacLeod 的〈Gone Beyond〉，怪核使用專案的本地懸疑音景。曲目與授權資訊見 [音訊素材說明](public/assets/audio/README.md)。
