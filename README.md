# 夢隙：醒來之前

使用 HTML、CSS、JavaScript 與 Three.js 製作的第一人稱 3D 夢核／怪核密室逃脫。五個場景包含影子對齊、道具收集、照片拼圖、記憶電話總機及電路點燈；每關完成後自動保存在此瀏覽器。

## 線上遊玩

**[開啟《夢隙：醒來之前》](https://shao077777714.github.io/midexam/public/)**

GitHub Pages 目前從 `main` 的根目錄發布，遊戲入口位於 `public/index.html`，因此網址需要保留 `/public/`。不必啟動本機伺服器，可直接把連結分享給其他人。

後續更新遊戲時，先將開發分支合併到 `main`，等待儲存庫的 Pages 部署完成，網址會維持相同。本機網址與公開網址使用不同的瀏覽器存檔，進度不會自動轉移。

## 本機執行

安裝 Node.js 後，在此專案資料夾執行：

```powershell
npm ci
npm run build
npm run dev
```

開啟終端顯示的 **http://127.0.0.1:4173/**。伺服器只提供本機靜態檔案，沒有後端遊戲服務、帳號或資料庫。停止時在終端按 Ctrl+C；如需改埠號，可先在 PowerShell 設定 `$env:PORT = '4174'`。

`npm run build` 將固定版本 Three.js 0.186.1 及授權複製到本機素材目錄，並建立可部署的 `dist/`。遊戲不依賴外部 CDN；將 `dist/` 內容放到一般靜態網站空間即可。請透過 HTTP 網址使用，勿直接雙擊 HTML。

## 操作方式

| 操作 | 按鍵／方式 |
| --- | --- |
| 移動、環視 | WASD；探索時隱藏游標，直接移動滑鼠環視，無須按住 |
| 互動、拿取 | 靠近可拿取物品後雙擊直接拿取；E 或中央互動按鈕仍可互動 |
| 放下、檢視 | G、R；檢視時拖曳旋轉，R／Esc 離開 |
| 物品欄、提示 | Tab、H |
| 暫停、退出操作介面 | Esc |
| 輔助探索 | N 開啟探索導覽，選擇目前可見的物件，沿可通行路線走近；WASD 可取消 |

物件操作介面會暫停玩家移動與環視。影子物件可調整左右、前後與角度；照片碎片可拖曳或點選放置並旋轉；總機依日期排列錄音，配電箱可旋轉或交換導電片。靠近物件才能使用，不提供直接跳關。

探索時直接移動滑鼠上下環視並優先鎖定滑鼠。按住 **Alt** 顯示游標、停止移動與環視，操作右上角調整區；放開後恢復。鎖定被拒時，畫布上下左右邊緣可持續轉向，點回場景重試鎖定。Esc 暫停、開選單及解謎面板直接有游標。淹水區步行與導覽速度為乾地的 55%。

## 五關流程

1. **失焦的房間：** 抽屜中的回診提醒觸發怪核，移動及旋轉月亮燈、兔子玩偶、花瓶，使影子對齊。
2. **沒有盡頭的走廊：** 拿起手機，探索座鐘夾層與家具，找齊鑰匙、孩子的畫、未寄出的信並放入凹槽。
3. **少了一個人的晚餐：** 從九個位置找回照片碎片，點選發亮後用 Q／E 或按鈕旋轉，支援拖放、交換及取回，拼合並翻面查看訊息。
4. **鏡子裡的陌生人：** 觸發諮詢紀錄，從三處夾層找齊三段錄音，在總機依清楚日期由早到晚排列，再接通。日期與逐字稿一直顯示，可取回重排；自動接線與調頻，靜音也可解。
5. **清醒之門：** 尋找燈泡／燈罩／電池修復三盞燈，移動及旋轉配電箱導電片接通三個接口。依過去→現在→未來點燈，觀看投影後將第二關的信投入信箱。

故事、精確謎底與完整驗收條件分別見 `brief.md`、`agent.md`、`verify.md`。遊戲以約 25 分鐘設計，沒有強制倒數；實際時長需由玩家試玩驗證。

## 存檔

平常只顯示右上角的雙肩背包圖示。點圖示或按 **Tab** 開啟右側正方形物品欄，顯示本關尚需使用的道具縮圖與名稱；點選後高亮並保留面板。點右上叉叉、背包或按 **Tab／Esc** 收起，回到探索後按 **R** 檢視選取物件。物品多時只捲動格子區，不會展開全螢幕。用過的物品收起，取回後恢復；放下不會刪除任務道具，第二關信件在第五關需要投遞時重新顯示。

每關完成及進入下一關時，使用 localStorage 的 `dream-gap-save-v1` 儲存進度。關閉或重新整理後，從主畫面的「繼續上一次的記憶」載入。同一網站來源與瀏覽器才能讀取同一進度；無雲端同步。第二關信件的跨關資格會保留。儲存鍵沿用原名稱，格式升為 version 4；接受 v1、v2、v3。保留已完成關卡、記憶、信件與已完成投影；舊版未完成的第四／五關會改玩新總機／電路，新機關擺位與步驟可存檔續玩。投影中重載可再次播放，不會卡在黑畫面。

寫入失敗時會顯示重試提示，不會假裝已儲存。開始新遊戲會在確認後取代該來源的進度；成功操作後亦會保存中途狀態。

互動預覽共用繪圖環境；繪圖中斷時會嘗試恢復，無法恢復則提供重新載入提示。如果舊頁面已白屏，載入修正版後按 Ctrl+F5，再選「繼續上一次的記憶」，不需要清除網站資料或開始新遊戲。公開站仍須等待開發分支合併 main 後才有修正。

## 素材與結構

- `public/`：可執行的靜態網站來源。
- `public/assets/dreamcore/`：Image Gen 生成貼圖、家庭照片、完整提示詞與清單。
- `public/vendor/`：固定版本 Three.js 原始發佈檔及 MIT 授權。
- `references/visual-style/`：九張使用者提供的風格參考原圖，未修改。
- `public/engine.mjs`：五關狀態、謎底與存檔驗證。
- `public/scene.mjs`：Three.js 場景、模型、投影與互動目標。
- `public/game.mjs`：操作介面、導航、故事、聲音與遊戲流程。
- `public/controls.mjs`、`public/phenomena.mjs`：滑鼠鎖定／自由環視、水中速率及附著／落地異象。
- `public/models.mjs`、`public/spatial.mjs`、`public/atmosphere.mjs`：道具造型、支撐／碰撞、無盡遠景及壁面眼睛。
- `tests/`：Node.js 原生測試。

環境音及機關聲由瀏覽器合成；語音使用瀏覽器 Web Speech，保留完整文字。語音自動優先挑選可用的中文男聲，音高 0.74、語速 0.82，不提供更換聲線的介面；無中文聲線時保留字幕。右上角燈泡開啟任務提示、喇叭切換全部聲音、星芒切換眼睛與水面動態，另有雙肩背包與暫停圖示，滑入可看說明。背包平常收起，點背包或 Tab 開啟右側方形物品欄，直接選物後高亮；叉叉、背包、Tab／Esc 收起，關閉後 R 檢視選取物品。探索導覽保留 N 快捷鍵；系統減少動態偏好另有靜態回退。原始參考圖只供開發風格參照，遊戲實際場景使用程式建立的模型及生成素材。

探索優先鎖定滑鼠，可上下環視到 ±85°；按住 **Alt** 顯示游標並停止移動／環視，放開恢復。面板直接有游標；Esc 暫停。瀏覽器未授予鎖定時，畫布上下左右邊緣可持續轉向，點場景重試。怪核窗外眼睛持續可見，降低動態時維持靜態。
