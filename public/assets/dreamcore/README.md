## 兩種環境的美術設定

下表記錄本包生成時的前期美術構想；正式開場、關卡與切換規則以專案根目錄 `brief.md` 的最新五關企劃為準。

| 元素 | 清醒後所在的夢核環境（圖 1） | 不時切入的異常環境（圖 2） |
| --- | --- | --- |
| 房屋 | 重複排列的粉彩獨棟房屋 | 蒼白、失去色彩的房屋 |
| 草地 | 鮮綠、整齊且略顯人工 | 同一張貼圖降低飽和度與亮度作為初步方案 |
| 道路 | 延伸到遠方的紫灰道路 | 可沿用幾何與貼圖，調整環境光線 |
| 天空 | 由場景設定明亮藍色；本包未另附藍天圖片 | 使用黑底眼睛全景圖 |
| 切換 | 前期構想為主角醒來時的初始環境 | 前期構想為間歇性出現；最新企劃改依各關指定物件觸發切換 |

光線、色彩與場景切換是待實作內容，圖片本身沒有動畫。

## 使用邊界與待驗證項目

- 這是四張不透明 PNG 色彩貼圖，不含可旋轉的 3D 模型、碰撞體、角色、動畫或音效。
- 草地、道路與屋牆以可重複鋪設為生成目標，但尚未確認邊界逐像素連續；需要在實際網格上檢查接縫與重複感。
- 眼睛天空符合 2:1 比例，但尚未驗證球面投影、水平接縫或上下極點變形，不能視為已驗收的完整 skybox。
- 屋牆已有細微明暗紋理，並非無陰影的掃描材質；需在遊戲照明下確認效果。
- 本組未提供 normal、roughness、metalness 或位移貼圖，也不是 HDR 環境光素材。
- 已檢視生成圖片，確認沒有房屋或地面混入眼睛天空，且各材質無文字或水印。
- 已確認 PNG 可解碼及複製前後雜湊相同；尚未建立 Three.js 場景，因此未進行遊戲內驗收。

使用者提供的兩張圖片僅作方向參考，本包未重新發布原始參考圖。
