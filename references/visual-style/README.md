## 運用方式

- 夢核：柔和粉彩、柔光、空無一人的熟悉場所、童年布置，以及室內花草或不合常理的水面。
- 怪核：同一空間的冷光、灰綠或褪色材質、類比雜訊、影像色差、漂浮眼睛、鏡面異常與被注視感。
- 依 `brief.md` 的五關設計選用材質、燈光與道具線索；這九張圖不代表新增九關，也不取代正式的關卡規則。
- 臥室可參考圖 2、5 的色彩與柔軟材質；走廊可參考圖 1、7、9 的深度與違和感；家庭餐廳可參考圖 3 的無人慶典感。圖 4、6、8 可提供孤立感、怪核天空與影像失真的視覺語彙。以上為美術建議，不改動劇情或謎底。
