# 劇情與謎題內容包

六個 `level-N.json` 記錄目前敘事、線索、三階企劃提示、答案及流程圖道具。以 brief／verify 的2026-11-03最新修訂及 agent 本輪規格為準，取代歷史聲音排序、因果齒輪及第五關投信；舊稿演變保留於 Git 歷史。所有關卡完成後需親自開實體門；第六關先投信再開最後的門。實際遊戲的即時目標與60秒／30秒五層提示維護於public/guidance.mjs，與本包的三階企劃提示分開。

第二關是時間及圖形連鎖搜尋；第四關是爸爸的空房間，無鏡子，五處找齊五錄音日期排序；第五關單擊旋轉、拖放交換銅片，真正接通後依序點燈並投影；第六關是約52公尺的黑暗走道，分段紅字／家庭回憶／眼睛，最後投信再親自開門。六場景仍只有五片記憶。這些 JSON 是對應企劃資料，遊戲執行資料目前維護於 public/content.mjs 與 engine／puzzles，不宣稱 JSON 已接入程式。
